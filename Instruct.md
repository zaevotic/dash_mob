# The Ultimate resurrection formula for an old android phone

This project aims to repurpose old phones for useful things that one might require a second monitor for.

## The purpose:
I have this old M34 which I was supposed to root, but because Samsung is Samsung, I can't root it since the thing is firmware locked. SOOOO instead of trying to root it, I thought why not create an app that doesn't require rooting and would still do the job well as a helper screen instead? like, ever thought of cool alarm clocks but thought you'd never afford them? This. Is. It.

## The goal:
I want to make this phone serve as a personal dashboard, that can help me track my daily habits, act as an alarm clock with customizable options, and... a media player that works by offloading whatever a user might be watching on their laptop to their new and sleek alarm clock. (No, streaming is not an option since it's not fun.) I also want to include other features like local-network wide server where I can store media upto 128GB (SD card) and is configurable (settings and everything) from both my laptop and my phone. and it has to have a very specific aesthetic. Later once you're done, explain how I'm supposed to set everything up" - an old prompt but useful here

Make sure to have a clock be on the phone as default, so that it also serves as a hi-tech alarm clock, which is again manageable from my PC or my other phone. so the structure is gonna be something like:

[My m34 phone that's running this server / app thingy that displays the dashboard] <--- my main phone having an app that serves as a management app for the server, same with my desktop. (local network accessed for now, I'll see later if a VPN is possible.) so I want the main phone to control the server, and the management app should be available on both my main phone, and my desktop (which will be sitting on my desk.)
